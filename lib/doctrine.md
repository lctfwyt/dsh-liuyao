# 六爻断卦体例

本规程用于解读本工具输出的卦盘字段，只依据盘面已有信息推断，不引入盘外信息。

## 一、总原则

1. **先定用神**（用神＝所问之事的代表爻）。第一步不是看吉凶，而是由 `question` 在 `lines` 的 `relative` 中找出代表爻。问"求职"与问"母亲病情"用神不同，结论可能相反；用神错则全盘作废。
2. **月建日辰为纲**。`monthBranch`（月建，按节气定的当月地支）与 `dayBranch`（日辰）能生克任何一爻，包括动爻与变爻，是全局权力最大的两股力量。
3. **动爻为重**。`moving:true`（发动之爻）是有行动力的力量，优先级高于安静爻；`staticHexagram:true`（六爻安静）时改以世应、月日生克与 `flags` 格局论事。
4. **卦名卦象为辅**。`primary.name`、`flags`（六冲/六合/三合局等）、游魂归魂只作倾向性加减分，不得单独下结论。
5. **一事一断**。同一卦盘只回答 `question` 所问那一件事，不顺带断他人他事。

## 二、取用神口诀

用神即 `lines[i].relative` 中对应的六亲。

| 所问事项 | 用神 | 白话解释 |
| --- | --- | --- |
| 求财、生意、投资、薪资、回款 | 妻财 | 钱与可变现之物 |
| 求官、求职、升迁、考试、官司、疾病之症 | 官鬼 | 管束我者与名分、职位、病症 |
| 父母、长辈、文书、合同、房产、车辆、证件、天气 | 父母 | 庇护我者与凭据类实物 |
| 子女、下属、学生、宠物、平安、解忧、医药 | 子孙 | 我所生养、能解灾者 |
| 兄弟、朋友、同事、竞争者、合伙人 | 兄弟 | 与我同类、分我之财者 |
| 自身吉凶（问"我这次如何"） | 世爻 `isShi` | 求测人本人 |

补充：问婚姻，男以妻财为妻、女以官鬼为夫，兼看 `ying`（应爻）为对方态度；寻人寻物兼看应爻与用神爻位（初爻主近处身下，上爻主远处高处）。

**用神多现**（同一六亲出现两爻以上）：取与世爻相近、与动爻相关、得月日生扶、不空不破者为主用神；其余作"事有反复、多方参与、有第二笔财/第二个候选人"的旁证；一空一实取实，一旺一衰旺者为用、衰者示阻力。

**用神不上卦**：查该用神对应的 `fushen`（伏神，藏在飞神之下的爻）。① 伏神得月建或日辰生扶，或飞神被冲克、逢空逢破，则伏神可起，事迟而有成；② 伏神休囚又被飞神压制，主事藏不露、求而不得；③ 只用 `fushen` 字段自带信息，不另行推演伏神。

## 三、旺衰判断

1. **生克来源**：`monthBranch` 主外部与上层环境，`dayBranch` 主当下实际助力。月生用神＝有靠山；日生用神＝立得实惠；月克日生＝有压力但可周转；月日同克＝事难成，除非动爻有力来救。
2. **旺相休囚死**（相对月建）：与月建同五行＝旺；月建所生＝相；生月建者＝休；克月建者＝囚；被月建克者＝死。旺相有力，休囚死纵有吉象也力弱。
3. **月破**：`isMonthBroken:true`（与月建相冲）当月基本失效，须出月或逢合之日才转机；用神月破主事散、物坏、约毁。
4. **日破**：爻与 `dayBranch` 相冲又不旺、无月建生扶者作日破（当日无力）；若旺相仅断"当日受挫、有变动"。
5. **旬空**：`isKong:true` 即地支属 `xunKong`。空＝虚、不到位：吉神空则吉不实，凶神空则凶暂不至。
6. **出空与填实**：出空＝过本旬；填实＝逢该地支之日或月。二者是最常用的应期依据。
7. **暗动**：安静之爻被 `dayBranch` 相冲而本身旺相者，为暗动（无声自动，主暗中生变），能生克他爻但力小于明动。
8. **本工具默认口径**：月建一律按节气（以 `monthBranch` 为准，不看农历月）；日辰以子时换日（以 `dayPillar` 为准）；旬空以日柱推（以 `xunKong` 为准）。流派中有按年柱月柱论空、以子正换日者，本工具不采用。子时换日下，23:00 之后起卦者 `calendar.civilEffectiveDay` 为换日后的有效日期（可能比钟面日期多一天），`calendar.dayRolled:true` 即标记这一情况；日柱按 `civilEffectiveDay` 取，与「起卦」行显示的当地钟面时间不一致属正常，不是排盘错误。

## 四、动变分析

1. **动爻生克用神**：动爻生用神＝有推动、事顺；动爻克用神＝阻力、竞争、损耗；动爻自身被月日克制则力量打折。
2. **进神/退神**：动爻与 `变爻` 同五行同六亲，地支顺行为进神（事渐强、量增），逆行为退神（事渐衰、量减）。
3. **化空**（变爻逢旬空）：动了却落空、承诺未兑现，待变爻出空填实方见结果。
4. **化破**（变爻与月建相冲）：半途损坏，旧事回头又成空。
5. **化墓**（变爻为该五行墓库：木未、火戌、金丑、水辰）：被困、被收、隐藏不动、病入里，逢冲开墓库之日解。
6. **化绝**（变爻为该五行绝地，如金化寅、木化申）：事断、缘尽、力竭，用神化绝最忌。
7. **化回头生**（变爻生动爻，如午火化寅木）：得后续助力，先难后易，吉。
8. **化回头克**（变爻克动爻，如午火化子水）：自伤反噬，事起而终挫，凶。
9. **动爻与世应**：生动世＝得利有人助；克世＝受制担险；冲世＝变动奔波分离；合世＝黏住我，成事或纠缠。动爻对应爻同理，用于看对方与环境。
10. **多爻齐动取舍**：① 先找用神及与用神直接生克之动爻；② 看动爻之间是否连环；③ 再看世应受影响；④ 最后以 `flags` 格局收尾。多动主事杂、多头并进、过程曲折。`staticHexagram:true` 时跳过本节。

## 五、世应关系

1. **世爻 `isShi`＝求测人**：旺衰看自身状态；`isKong` 主心里没底或行动落空；`isMonthBroken` 主根基受损。
2. **应爻 `isYing`＝对方、对手、环境、远方**：应生世＝对方相就、环境有利；应克世＝对方施压；世生应＝我方付出；世克应＝我能掌控。
3. **世应相冲**：意见相左、分离、谈不拢；求合作主散，求婚姻主不合，求讼主对抗激烈。
4. **世应相合**：成交、黏合、和好；但合亦主拖住不放，求脱身反不利。
5. **世应俱空**＝双方皆无实意；世空应实＝我退他进；世实应空＝对方无力，我占先；用神生世最佳，用神克世受制，用神合世主成、冲世主变。

## 六、卦象格局

1. **六冲卦**：主快、散、分离、变动。求财求官多难聚或速成速散；病主急来急去；寻人主走失在动、方向不定；求脱身脱离纠纷反吉。
2. **六合卦**：主慢、聚、成、拖。求财合作主成局；讼主久拖；病主缠绵；求离散不利。
3. **反吟**：内外卦互冲类，主反复颠倒、计划推翻重来、成而再变。
4. **伏吟**：内外卦同象类，主停滞、原地打转、内耗，事不动人不动。
5. **三合局**：三爻合力成局，主多方汇聚成势。合局生用神＝众助成大功；合局克用神＝群力来攻；用神不在局中＝事不由我、另起一枝；局中有空破＝虚合，须填实方应。
6. **游魂卦**主心意不定、外出搬迁、悬而未决；**归魂卦**主回归、旧事重提、找回旧人旧物，寻人寻物多吉。
7. 格局只作修正项：格局吉而用神凶仍以用神断；格局凶而用神旺断为"路难走但能到"。

## 七、六神取象

`spirit`（六神）给六亲加色彩，不单独定吉凶——先定六亲，再用六神定性质与场景，二者冲突时以六亲为主。

| 青龙 | 喜庆、正财、贵气、酒色、生育 | 临妻财＝正当收益；临官鬼＝正途官职，亦主酒色之累 |
| 朱雀 | 口舌、文书、消息、宣传、火灾 | 临父母＝文书合同消息；临官鬼＝口舌官司 |
| 勾陈 | 田土、房产、拖延、羁绊、旧事 | 临父母＝房产契据；临兄弟＝旧友纠缠、合伙扯皮 |
| 螣蛇 | 虚惊、怪异、缠绕、忧疑 | 临官鬼＝忧虑惊恐、无名病痛；临妻财＝来路不明之财 |

## 八、应期推断

应期＝事情落实的时间。取法可叠加，多法指向同一时段则可信度提高：① **值日值月**——用神地支逢日辰或月建；② **冲开**——用神被合住或入墓，逢冲该地支之日月；③ **填空**——`isKong:true` 之爻逢该地支出空；④ **冲用神**——用神安静而事需变，逢冲之日月动而成；⑤ **合处逢冲**——合局致迟滞，逢冲该合解局；⑥ **爻位期数**——初爻主数日内、二爻约旬日、三爻约半月、四爻约一月、五爻约一至三月、上爻主三月以上或跨季（数理参考，非硬日期）；⑦ **变爻地支**——化空化破化墓者，以变爻地支填实或冲开之时为应期。

**交付口径**：一律给区间与先后次序（如"三日内有回音""一至两周见分晓""本月难有实质进展，出月转机"），禁止给绝对日期或精确到某时；各法指向分散时，直接说明"时间信号不一致，宜按区间观察"。

## 九、按事项的断卦要点

**财运/生意**：① 以妻财为用，子孙为财源客户。② 妻财旺相又得动爻生＝进财可期；妻财空破＝钱不落地或账期拖延。③ 子孙旺而妻财衰＝有客无利；兄弟发动＝分财竞争、成本上升。④ 世克妻财＝我能掌控；世空＝我无力承接。⑤ 六冲主快进快出，六合主长期合作。⑥ 妻财临玄武或白虎，提示核实款项来路与风险。

**事业求职**：① 官鬼为职位上司，父母为文书合同。② 官鬼旺相生世且父母不空＝录用可成。③ 官鬼空破或克世＝岗位虚设或上司压制。④ 子孙发动克官鬼＝不利求官，宜另择时机。⑤ 世应相合主双方合意，相冲主谈不拢或岗位有变。⑥ 游魂卦主职位不定或需外调。

**婚姻感情**：① 男取妻财、女取官鬼为配偶用神，应爻为对方实际态度。② 用神与世相生相合＝情投意合；相冲相克＝不合争执。③ 用神空破＝对方心不在或关系有名无实。④ 用神多现＝身边不只一人或多段情缘。⑤ 六冲主散、六合主成亦主拖、反吟主分合反复。⑥ 玄武临用神只作"或有隐瞒"的提示，不作定论。⑦ 问复合兼看归魂卦与合处逢冲。

**健康**：① 官鬼为病症（或按所问部位取象），子孙为医药与解忧，世爻为本人。② 世爻旺相、官鬼受制＝底子尚可、症可控。③ 官鬼旺而克世、子孙空破＝症重药轻，应明确建议就医。④ 问长辈以父母、问子女以子孙为用，化墓化绝为警讯。⑤ 白虎临官鬼主急症血光外伤，螣蛇临官鬼主疑病缠绵。⑥ 本工具只描述传统文化倾向，绝不给诊断、用药或停药意见。

**考试文书**：① 父母为文书成绩与通知，官鬼为名次与主考方，子孙解官不利功名。② 父母旺相不空、官鬼生世＝录取有望。③ 父母空破＝文书缺失、通知延迟、材料有误。④ 朱雀临父母主答辩消息，临官鬼主口舌争议。⑤ 应期取父母地支值日值月或出空之时。

**出行**：① 世爻为出行人，父母为车船机票证件，官鬼为路途阻碍，子孙为平安。② 世旺、子孙旺而官鬼受制＝顺利。③ 六冲主行程快而多变动，伏吟主滞留推迟。④ 白虎临父母或官鬼，提示交通风险，宜改期并注意安全。⑤ 应期看冲世、冲应或父母填实之时。

**寻物找人**：① 按所寻之物取六亲（财物取妻财、证件取父母、子女取子孙），应爻为所在之处。② 用神在初、二爻主近处家中身下；在五、上爻主远处高处外地。③ 用神逢空＝暂找不到或已移动；逢合＝被藏起或有人保管；逢冲＝已离原处。④ 归魂卦、世应相合多可寻回；六冲、游魂多难寻或人已远走。⑤ 玄武临用神主被窃或藏匿。

**官司诉讼**：① 世为我方、应为对方，官鬼为官方与案件，父母为状纸证据，子孙为解讼之神。② 官鬼生世、父母旺相＝我方有理有据且得官方倾向。③ 官鬼克世、子孙空破＝我方受制且难化解。④ 世应相冲主对抗升级，相合主调解和解。⑤ 六合主久拖难结，六冲主速决而结果两分。⑥ 妻财发动克父母，防证据或费用出问题。

## 十、输出格式要求

每次解读按以下六段输出，**每条判断必须引用卦盘具体字段**（如"官鬼在二爻发动、月建生之、日辰不克，故……"），禁止"总体不错""需要注意"这类空泛断语。

1. **一句话结论与吉凶倾向**：直接回应 `question`，给"吉/偏吉/吉凶参半/偏凶/凶"之一并附一句理由。
2. **用神与旺衰**：写明取何六亲为用神及理由，引用该爻 `position`、`relative`、`element`、`branch`、`isShi/isYing`、`isKong`、`isMonthBroken`，以及 `monthBranch`、`dayBranch` 的生克与旺相休囚死判定。
3. **动变与关键爻的作用**：逐条列 `moving:true` 之爻及其 `变爻`，说明对本爻、用神、世应的作用（进退神、化空破墓绝、回头生克），并说明 `flags` 与游魂归魂的修正。
4. **应期区间**：按第八节给出区间与先后次序，标注依据（填实/冲开/值日值月/爻位），说明信号是否一致。
5. **建议与规避**：2-4 条可执行提示，用"可留意/宜暂缓"等建议性表达。
6. **声明**：固定附上"以上解读基于传统六爻（纳甲筮法）文化体例，仅为传统文化参考，不构成决策、法律、投资或医疗建议；涉及健康、诉讼、重大财务事项请以专业意见为准。"

格式约束：结论先行；术语首次出现用括注给白话解释；不重复同一判断；不得输出卦盘以外的信息（具体人名、机构名、真实金额、真实诊断等）。

## 十一、本工具的实现边界

1. **可用字段**：纳甲干支 `najia`、六亲 `relative`、六神 `spirit`、世应 `isShi/isYing`、伏神 `fushen`、旬空 `isKong`/`xunKong`、月破 `isMonthBroken`、宫位与宫五行 `palace`/`palaceElement`、变卦与变爻 `changed`、卦名与格局 `name`/`flags`、四柱与月建日辰、`staticHexagram`。
2. **本工具不提供**：飞神（伏神上下文除外）、卦身、命爻、六神之外的杂占（神煞、贵人、驿马、桃花、纳音、太岁冲及奇门六壬类信息）、"得地失地"等额外排盘结论。
3. **因此不得**：虚构卦盘中没有的爻、六亲、神煞或数值；声称看到未提供的历史卦例；把流派分歧写成确定结论；缺字段时假装推断——应说明"卦盘未提供该项，无法判断"。
4. **默认口径一览**（流派有差异时以本工具为准）：月建以节气定（非农历月）；日辰以子时换日（23:00 起算次日，`civilEffectiveDay` 为有效日期）；旬空以日柱推；月破以爻与月建相冲论；动爻作用力以月日为最终裁定；应期只给区间不给绝对日期；六神只作色彩不作吉凶主断。换日口径为引擎内部固定值，不由调用方选择。
